First run

Three steps to your first answer.

Install & unzip

Unzip the download, then run pip install -r requirements.txt. Python 3.11+ on Windows 10 (2004+) or 11 gives you the full screen-share-safe overlay.

Add your keys once

Copy offerpilot_keys.example.json to offerpilot_keys.json and paste your model keys. Your keys stay on your machine, so your usage is yours and private.

Pick a company & go live

Run python company_launcher.py, choose where you're interviewing, and the copilot opens grounded in a Q&A set built for it. Hold M to pause, P for ghost mode.
