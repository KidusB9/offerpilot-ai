Requirements & quick start

A Python desktop app. Three steps to running.

OfferPilot ships as a Python desktop app so transcription and models can run locally. You need Python 3 installed. Nothing about your audio or screen leaves the machine once you are set up.

Unzip the download

Extract offerpilot-desktop.zip anywhere you like, then open a terminal in that folder.

Install dependencies

Install the Python requirements with pip install -r requirements.txt.

Add your keys

Copy offerpilot_keys.example.json to offerpilot_keys.json and paste in your keys. Launch with python app.py.

Optional, for the fully offline path: drop the Vosk small English model into ./models/ for on-device speech-to-text, and install Tesseract to OCR captured coding screens.

quick start · terminal🛡 on-device
# 1 · unzip and open a terminal here
unzip offerpilot-desktop.zip

# 2 · install Python dependencies
pip install -r requirements.txt

# 3 · add keys, then run
cp offerpilot_keys.example.json offerpilot_keys.json
python app.py

vosk-model-small-en-us  → ./models/
tesseract  → coding-screen OCR

Hotkeys reference

Drive the overlay without touching the mouse.

Every action is a global shortcut, so you stay in the call and the overlay stays out of sight.

Ctrl · Alt · S

Capture the coding screen and OCR the prompt.

M

Pause and resume live transcription.

P

Ghost mode. Dim the overlay instantly.

Ctrl · Alt · H

Hide the overlay entirely.
